Клиент для Android на основе Chatwoot Mobile 4.11.5. Скачать нужно файл с расширением `.apk`. Сборка поддерживает ARM64 (включая Honor Magic6 Pro) и x86_64.

Установите APK поверх подписанной версии 0.7.0. Включите Tailscale и один раз войдите по почте и паролю Chatwoot. При необходимости подтвердите вход кодом. Рабочий сервер и русский язык уже выбраны. При наличии доступа откроется аккаунт 2.

CI сверяет подпись и проверяет обновление на эмуляторе. Сквозная доставка из Telegram через собственный Firebase на Honor, включая заблокированный экран, требует проверки в рабочей сети.
