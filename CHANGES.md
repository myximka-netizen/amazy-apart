# Доработки сайта «Волшебно тут | Amazy Apart»

## Что изменилось

- Единое название бренда, контакты и прямые ссылки на бронирование.
- На главной и в каталоге показана существующая акция Online5: 5% на первое бронирование. Значения взяты из исходного раздела предложений; новая постоянная скидка не вводилась.
- Добавлены страницы `/business-travel/`, `/long-stay/`, `/apartments/dinamo/`, `/apartments/leningradskiy-prospekt/`, `/apartments/carskaya-ploshad/`.
- Предложения на 5, 7, 14 и 30+ ночей: для 7 и 14 ночей сохранены существовавшие в исходном сайте скидки 5% и 10%; для остальных сроков предлагается расчёт без выдуманной цены.
- Русский язык по умолчанию, английские адреса `/en/`, китайские `/zh/`. Язык определяется адресом; внутренние ссылки сохраняют его.
- Контактная форма и форма на странице квартиры готовят сообщение в WhatsApp. Отправку подтверждает сам посетитель. Уведомление об успешной отправке без реальной отправки удалено.
- Вместо пустой карты добавлены ссылки на три района в Яндекс Картах; точные координаты квартир не выдумывались.
- Загрузчик HomeReserve переиспользует один скрипт, обрабатывает ошибку и повторную попытку. Доступна прямая ссылка на модуль и Telegram, даже если встраиваемый поиск не загрузился.
- Исправлены canonical, hreflang, Open Graph, JSON-LD, sitemap и ссылки на чужие домены. Из разметки компании убраны неподтверждённые сводные рейтинги, координаты и диапазон цен; исходные тексты других разделов сохранены.
- При `npm run build` создаются 42 HTML-страницы с заголовками, метаданными и основным содержимым, а также страница 404. Они доступны поисковикам без выполнения JavaScript.
- Добавлены цели Метрики для кликов на бронирование, телефон, мессенджеры и запросов корпоративного/длительного проживания. Успешная оплата не имитируется и не отслеживается как обычный клик.

## Проверка и сборка

```sh
npm ci
npm run check
npm run build
npm run verify:build
```

До дополнения по задаче #1 локально проверены TypeScript, производственная сборка, 42 HTML-страницы, единственность title/description/canonical, языковые ссылки, JSON-LD и наличие локальных ссылок/ресурсов. Проверено поведение общего загрузчика HomeReserve при параллельных вызовах, ошибке и повторе. Полный браузерный прогон не выполнен: Chromium недоступен в среде. Реальная оплата и применение скидок во внешнем HomeReserve не выполнялись.

## При публикации

Публикуйте **всю папку `dist`**, включая вложенные каталоги языков и страниц. Не заменяйте все ответы на главную `index.html`: сначала сервер должен искать существующий HTML маршрута. Сохраните SPA fallback для остальных адресов и настройку страницы 404 своего хостинга. Пример для nginx: `try_files $uri $uri/ $uri/index.html /index.html;`.

Никакие сообщения гостям не отправлялись, рассылки не добавлялись. Существующие настройки HomeReserve, аналитики, документы верификации Яндекса и фотографии квартир сохранены. Превью общих страниц, одобренный логотип и иконки обновлены. Итоговый результат CI проверяйте во вкладке Actions.

Загрузка этих изменений в GitHub не является проверкой публикации на amazy-apart.ru. Если хостинг подключён к этой ветке, публикация может запускаться его автоматизацией.

## Что остаётся проверить владельцу во внешних сервисах

- Применение Online5, 5% от 7 ночей и 10% от 14 ночей в реальном оформлении HomeReserve; возможность суммирования скидок не заявлена.
- Если нужен одинаковый прямой тариф для всех гостей, согласовать его размер и настроить в HomeReserve. Изменение текста сайта само по себе не меняет цену модуля.
- Конкретный состав корпоративных документов, безналичный расчёт и поздний заезд согласуются при обращении, а не обещаются безусловно.
- Страницы расположений ведут к общему каталогу. Фильтрация по району не имитируется: перед интеграцией нужны поддерживаемые параметры HomeReserve.
- Карточки `/apartment/1/`–`/apartment/3/` и отзывы перенесены из исходного проекта. Перед расширением каталога их содержание следует сверить с реальными объектами.
- Новые цели `booking_click`, `phone_click`, `telegram_click`, `whatsapp_click`, `corporate_request`, `long_stay_request`, `contact_draft` при необходимости создать в счётчике Метрики 104380673.
